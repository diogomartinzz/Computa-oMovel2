# Overview

## Purpose of the application
To retrieve and display a list of images from a public API using an Android application built with Kotlin and XML Views.

## Target users
Users looking to browse a gallery of random high-quality images.

## General idea of how the system works
The application uses the Picsum Photos API to fetch a list of image details. It uses a RecyclerView to display these images in a list format. The user can refresh the list using a swipe-to-refresh action.
